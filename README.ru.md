Музыка с Mac → лампы Yeelight (music mode) и WiZ в реальном времени. TUI со спектром, долями и живыми плашками ламп.

## Установка

```bash
brew install mechanicpanic/tap/lampa
```

Собирается из исходников (нужны Xcode Command Line Tools для Swift).

## Сборка

```bash
make            # bin/lampa-tap (Swift) + bin/lampa (Go)
make test
```

Нужны macOS ≥ 14.4, Go, Swift. При первом запуске macOS спросит разрешение на запись звука для терминала.

## Запуск

```bash
bin/lampa discover --save   # найти лампы и записать в ~/.config/lampa/config.toml
bin/lampa                   # весь звук системы
bin/lampa --dry             # без ламп, только экран
bin/lampa --wav track.wav   # из файла
bin/lampa --lang en         # английский интерфейс (по умолчанию русский; t переключает)
```

Клавиши: `1–6` режим (Pulse, Spectrum, Chase, Ambient, Drop, Meter), `p` палитра, `←/→` чувствительность, `↑/↓` задержка света, `s` источник звука, `l` выбор ламп (вкл/выкл, запоминается; `h` там скрывает выключенные; или просто кликни по карточке — в группе по полоске этажа или по названию), `d` поиск ламп, `t` язык, `space` пауза, `q` выход (лампы вернутся как были), `?` подробная помощь. `lampa help` в терминале объясняет флаги, клавиши и конфиг.

## Роли ламп

В режиме Spectrum (`2`) каждая лампа следит за своей частью звука. Это задаётся для каждой лампы в `~/.config/lampa/config.toml`:

| `role` | за чем следит |
|---|---|
| `"sub"` | саб-бас, ниже 60 Гц |
| `"bass"` | бас и бочка, 60–250 Гц |
| `"lowmid"` | низ середины, 250 Гц – 1 кГц |
| `"mid"` | середина и вокал, 1–4 кГц |
| `"high"` | хэты и тарелки, выше 4 кГц |

```toml
[[lamp]]
  name = "hero"
  role = "bass"

[[lamp]]
  name = "потолок"
  role = "high"
```

Лампы без роли берут бас, середину и верх по очереди. Остальные режимы роли не читают: Pulse мигает всеми лампами в долю, Chase бегает по ним по кругу.

## Лампы друг над другом

Лампочки, которые стоят одна над другой в одном светильнике, можно объединить в группу. У каждой одинаковый `group` и свой этаж, `level = 1` — нижняя:

```toml
[[lamp]]
  name = "икея низ"
  group = "ikea"
  level = 1
```

Тогда Spectrum кладёт бас вниз, а верхние частоты наверх, Pulse вспыхивает по этажам снизу вверх, как фонтанчик, Meter (`6`) заполняет светильник, как столбик громкости, а в интерфейсе группа — одна высокая карточка.

## Yeelight

Включи «LAN Control» в приложении Yeelight. lampa сама переводит лампу в music mode (без лимита 60 команд/мин); если модель его не поддерживает, работает медленно и пишет об этом на плашке.
